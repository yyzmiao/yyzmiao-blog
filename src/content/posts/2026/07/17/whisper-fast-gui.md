Whisper-Fast-GUI：一款为本地语音转写而生的极简桌面工具

## 背景

OpenAI 开源的 Whisper 模型在语音识别领域具备极高的准确率，对方言、中英混杂等复杂场景也有良好的适应能力。然而，将其部署到本地并稳定运行，对非开发背景的用户而言存在明显门槛：

-   **依赖环境复杂**：GPU 加速依赖 PyTorch 及配套的 CUDA 组件，环境变量配置不当极易触发 `cublas64_12.dll is not found` 一类的报错。
-   **交互方式原始**：多数方案仍停留在命令行层面，缺乏图形界面，操作成本高。
-   **功能颗粒度粗**：任务中途无法安全中断，输出格式单一，难以满足多场景需求。

Whisper-Fast-GUI 是针对上述问题设计的开源桌面工具，目标是将“本地语音转写”这件事简化为“双击运行、拖拽即用”。

**项目地址**：GitHub 仓库（详见原文链接）

* * *

## 核心特性

### 1\. 原生化启动体验

通过底层脚本封装启动流程，运行时不产生可见的命令行窗口，界面呈现方式与常规 Windows 桌面应用一致，避免了传统 Python 工具「黑框常驻」的问题。

### 2\. 推理引擎优化

底层采用 faster-whisper（基于 CTranslate2）替代官方原版实现，在同等硬件条件下推理速度提升明显，显存占用更低。同时内置动态库寻址机制，运行时自动完成 CUDA 核心库的链接，无需手动配置系统环境变量，规避常见的 `0xc0000142` 启动异常。

### 3\. 拖拽式任务队列

支持将音视频文件直接拖入窗口发起任务，处理过程中可继续追加文件，系统自动排队并按序执行，适配批量处理场景。

### 4\. 本地状态记忆

自动保存模型精度（推荐 large-v3）、计算设备选择及导出格式等配置项，下次启动无需重复设置。

### 5\. 多格式并发输出

单次转写任务同步生成 `.srt`（含时间轴字幕）、`.vtt`（网页播放器适配）与 `.txt`（纯文本）三种格式文件，覆盖字幕制作、内容归档等不同需求。

### 6\. 安全中断机制

支持任务运行中主动终止：程序会在完成当前语句识别后平滑退出，正确释放文件句柄与显存资源，避免异常卡死。

## 快速开始

bash

```
# 1. 克隆或下载项目到本地
# 2. 安装依赖
pip install -r requirements.txt

# 3.（可选，NVIDIA 显卡用户）安装 GPU 加速组件
pip install nvidia-cuda-runtime-cu12 nvidia-cublas-cu12 nvidia-cudnn-cu12

# 4. 启动程序
双击 Start-WhisperGUI.vbs
```

环境要求：Python 3.9 及以上版本。
