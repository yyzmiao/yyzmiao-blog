# 关于本站

你好，这里是 **一叶梓喵的小站**。

本站记录网络、系统、Android、AI 与开源工具相关的实践笔记，内容更偏向真实问题的排查过程和可以复现的解决方案。

## 技术栈

- 使用 [Astro](https://astro.build/) 构建纯静态页面
- 基于 [Firefly](https://github.com/CuteLeaf/Firefly) 博客主题定制
- 文章以 Markdown 管理，并通过 GitHub Actions 自动发布
- 评论由 Giscus 与 GitHub Discussions 提供

源码公开在 [GitHub](https://github.com/yyzmiao/yyzmiao-blog)。
