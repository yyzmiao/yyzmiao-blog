## 关于本站

- **内容定位**：个人实践备忘录，聚焦问题复现与可落地的解决思路。
- **源码开放**：博客源码完全公开在 [GitHub](https://github.com/yyzmiao/yyzmiao-blog)，欢迎提 Issue 或 PR 交流。

## 本站技术栈

- **框架**：[Astro](https://astro.build/) 构建纯静态页面
- **主题**：基于 [Firefly](https://github.com/CuteLeaf/Firefly) 定制
- **CI/CD**：文章以 Markdown 维护，由 GitHub Actions 自动化构建发布
- **评论系统**：基于 Giscus 与 GitHub Discussions
